TidyBot++ Collaborative Robotic Assistant

ME 326: Collaborative Robotics | Stanford University | Winter 2026

Hero photo/video of TidyBot++ in action

We built an intelligent robotic assistant using the TidyBot++ bimanual mobile manipulator. Our system interprets natural language commands — via voice or text — to perceive its environment, plan actions, and autonomously execute manipulation tasks. The robot can retrieve objects on command, perform multi-step sequential tasks, and open articulated furniture like drawers.

Methods

System Architecture

Our system follows a modular perception-planning-control architecture, orchestrated by an LLM-based planner.

System architecture diagram

Perception

SAM3 + RealSense D435

We use Segment Anything Model 3 (SAM3) combined with the Intel RealSense D435 depth camera to detect and localize objects in 3D space. Given a text prompt (e.g., "red apple"), the vision pipeline segments the object in the RGB image and projects it into a segmented 3D point cloud.

Principal Component Analysis

We use PCA to obtain the segmented pointcloud's major and normal axis, which is used to construct a grasp pose relative to the shortest width of the object and its centroid.

Pan-Tilt Camera

The camera is mounted on a 2-DOF pan-tilt unit, enabling the robot to scan its environment by sweeping across the scene.

Planning

LLM Planner (Google Gemini)

Natural language commands are processed by a Gemini-based planner that decomposes high-level instructions into a sequence of robot actions through automatic function calling. Available tools include scan, navigate_to, pick_up, place_at, open_door, and move_arm.

Voice & Text Input

Users can interact via text or voice (using the Gemini Live API for real-time speech understanding).

State Machine

The planner orchestrates task execution through a state machine that sequences perception, navigation, and manipulation actions, with error handling and replanning.

Control

Base Navigation

The 3-DOF holonomic base (Phoenix6 motors over CAN) navigates to target poses using the /approach_pose service. The base controller runs at 250Hz for smooth motion.

Arm Motion Planning

Inverse kinematics is solved using Mink (simulation) and Pinocchio (real hardware) with multi-seed IK for robust solutions. The IK planner handles the full 6-DOF WX250s arm workspace.

Gripper & Bimanual Coordination

Coordinated gripper open/close with force feedback for reliable grasping. Both arms can be controlled independently or in coordination for tasks requiring two-handed manipulation (e.g., drawer articulation).

Software Stack

ROS2 Humble Message passing, service calls, launch system
MuJoCo Physics simulation (500Hz physics, 100Hz state publishing, 30fps camera)
8 Custom ROS2 Packages tidybot_bringup, tidybot_control, tidybot_ik, tidybot_description, tidybot_msgs, tidybot_mujoco_bridge, tidybot_client, tidybot_network_bridge

Results

Task 1: Object Retrieval

The robot successfully interprets voice commands to locate, navigate to, and retrieve target objects in a cluttered environment.

VIDEO: Voice command → scan → navigate → pick → return

Key Results

  • Successfully identifies and localizes objects using SAM3 + depth
  • Navigates to objects and executes reliable grasps
  • Returns to starting position with object in hand

Task 2: Sequential Task

Given multi-step natural language instructions, the robot decomposes and executes chained actions.

VIDEO: "Find the red apple and place it in the brown basket"

Key Results

  • LLM correctly decomposes multi-step commands into atomic actions
  • Chains perception → navigation → pick → navigation → place
  • Handles different object/container combinations

Future Work

Improved Grasping

Integrate GraspAnything for 6-DOF grasp pose prediction, enabling more robust grasping of diverse objects in cluttered scenes.

Dynamic Replanning

Enhance the LLM planner with real-time failure detection and replanning — if a grasp fails or an object moves, the system should recover autonomously.

SLAM & Mapping

Add full SLAM capability using the onboard LiDAR for persistent environment mapping and long-range navigation.

Bimanual Task Complexity

Extend bimanual coordination to more complex tasks such as folding, packing, or tool use.

Human-Robot Collaboration

Develop shared-workspace capabilities where the robot can hand objects to humans, respond to gestures, and coordinate actions in real time.

Learning from Demonstration

Allow the robot to learn new manipulation skills from human demonstrations, reducing the need for manual programming of each task.
